# Google Form Quick Setup

1. Open Google Apps Script in your browser.
2. Create a new script project.
3. Paste the contents of google-form-generator.gs into the editor.
4. Save.
5. Run function: createUncleClarificationForm.
6. Authorize when prompted.
7. Open Executions or Logs and copy:
   - EDIT URL
   - LIVE URL
8. Send LIVE URL to your uncle.

Notes:
- The form is generated from your trimmed practical question list.
- You can edit the form manually after generation using the EDIT URL.
